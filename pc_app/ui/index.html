Ardzy

Your Zynq board, used like an Arduino.

  1. Pick or create a project on the left.
  2. Write main.py (ARM side) and/or build an FPGA design (Build FPGA or Vivado).
  3. Press Upload. Watch the program in the Monitor.

Write code

Snippets and Reference (top right) insert ready code; Ctrl Space suggests names; Outline jumps to any function.

Find mistakes

Check (Ctrl R) compiles; errors appear in Problems and as red marks in the editor. Click one to jump there.

Make it yours

Editor settings: font, size, colours, indent, ruler, auto-save, visible spaces, folding.

No typing?

The Blocks view makes programs from blocks, like Scratch. Learn teaches the FPGA step by step.

Simulate your Verilog before you build it. A testbench (a file named something_tb.v) makes the
              inputs of your design and shows what comes out, here as waves, in seconds and without the board.

              1. New testbench writes one for the project's top module (with the ARM side ready: dut.u_soc.write_ctrl(0, 5)).

              2. Set the inputs in it, then Simulate (F6). $display lines go to Output, mistakes to Problems.

              3. Here: tick signals on the left, mouse wheel = zoom, drag = move, click = cursor A, Shift+click = cursor B, click a bus name = draw it as a curve.

Keyboard shortcuts

    

      
Ctrl UUpload the project to the board and run it

      
Ctrl RCheck the project (compile / test without uploading)

      
Ctrl SSave the file

      
Ctrl F / F3Find in the file / find the next one (Shift F3 the one before)

      
Ctrl HFind and replace

      
Ctrl GGo to a line

      
Ctrl /Comment or uncomment the line

      
Ctrl + / - / 0Editor text bigger / smaller / normal

      
Alt ZWrap long lines on or off

      
Ctrl JHide or show the bottom panel

      
Ctrl ,App settings (language, colours, text, behaviour)

      
F6Simulate the Verilog (Simulation tab)

      
Ctrl SpaceSuggest names (Ardzy functions, pins, words of the file)

      
F2Reference of the word under the cursor

      
Ctrl Shift OOutline: jump to a function, module or signal

      
Ctrl Shift FSearch in every file of the project

      
Ctrl QFold or unfold the block at the cursor

      
Ctrl D / Alt Up DownCopy the line / move the line up or down

      
Ctrl 1 ... 9Code, Board, I/O, Tools, Ready projects, Learn, Map, System, Blocks
