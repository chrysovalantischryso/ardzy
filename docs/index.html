Project history

  1. FM/AM transmitter (earlier): the board as a radio transmitter, RDS text "TEST", web control page. Showed that the FPGA works and taught us the board's real chip (XC7Z010).
  2. Clean Linux: fresh Debian 12, old boot files kept. Small, clean, safe.
  3. Ardzy 0.1: everything from source, the boot loader's memory settings taken 1:1 from the proven one, Arduino-style upload system and the Ardzy app. Runs on the real board.
  4. Ardzy 0.2 BETA: FPGA designs built inside the app (no Vivado), Arduino C++ and libraries, instruments in the FPGA (logic analyzer, PWM, frequency meters, UART, I2C), Map and System views, Ardzy OS 0.2 written and updated from the app.
  5. Next: an FPGA block for WS2812 LEDs (NeoPixel timing), more instruments, your own designs.
